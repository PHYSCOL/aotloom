# AOTLoom

**Interactive Proposal Studio for freelance web projects.**

AOTLoom turns a loose client conversation into a practical project scope, delivery path, and client-ready proposal. It is designed as a fast, browser-based tool for planning web projects without spreadsheets.

## What it does

- Builds a live visual scope map from project inputs
- Calculates a transparent complexity score, timeline, and investment range
- Creates a client-ready proposal summary
- Saves drafts locally in the browser
- Copies the brief, exports Markdown, and supports browser Print-to-PDF
- Works entirely in the browser — no account, API key, or backend required

## Built with

- HTML
- CSS
- JavaScript
- Browser APIs: Local Storage, Clipboard, Blob download, Print

## Run locally

Clone the repository and open `index.html` in a modern browser. No build step is required.

## Notes

The pricing ranges are illustrative planning estimates, not fixed quotations. The calculation logic is intentionally visible and deterministic so that the tool remains explainable and easy to adapt.
